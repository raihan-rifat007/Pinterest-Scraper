CORE MODULES (core/):
======================

scraper.py (200 lines):
  - PinterestScraper class
  - search(query, limit) - Search pins
  - get_board_pins(url, limit) - Get board content
  - get_related_pins(pin_id, limit) - Related pins
  - Pin data extraction and formatting

http.py (80 lines):
  - ProxyRotator class
  - build_session() - Create HTTP session with retries
  - get_random_user_agent() - User agent rotation
  - Automatic retry on rate limits

downloader.py (120 lines):
  - FileDownloader class
  - Concurrent downloads with ThreadPoolExecutor
  - Resume interrupted downloads
  - Progress tracking and statistics

dedupe.py (85 lines):
  - DedupeStore class
  - Persistent JSON-based deduplication
  - Add, check, and manage seen pins
  - Deduplicate pin lists

storage.py (140 lines):
  - StorageManager class
  - save_json() - JSON export
  - save_xlsx() - Excel export
  - save_csv() - CSV export
  - create_zip() - ZIP export with metadata
  - Automatic file cleanup

INSTALLATION & USAGE:
======================

Local Installation:
  $ pip install -e .
  $ pip install -r requirements.txt

Start Server:
  $ python -m __main__ server
  or
  $ python -m __main__
  or
  $ pinterest-scraper server

CLI Usage:
  $ pinterest-scraper search "nature photography" -l 50
  $ pinterest-scraper board "https://pinterest.com/user/board"
  $ pinterest-scraper export pins.json -f xlsx

Docker:
  $ docker-compose up
  $ curl http://localhost:8080

Web Interface:
  Open http://localhost:8080 in browser


API ENDPOINTS:
===============

Health Check:
  GET /api/health
  Returns: {status, version, timestamp}

Start Scraping:
  POST /api/scrape
  Body: {query, mode, limit, download, workers, ...}
  Returns: {job_id}

Monitor Progress:
  GET /api/jobs/{job_id}/events
  Returns: Server-Sent Events stream

Get Results:
  GET /api/jobs/{job_id}/result
  Returns: {status, pins, stats}

Cancel Job:
  POST /api/jobs/{job_id}/cancel
  Returns: {status, job_id}

Download ZIP:
  GET /api/jobs/{job_id}/download/zip
  Returns: File download

Download XLSX:
  GET /api/jobs/{job_id}/download/xlsx
  Returns: File download
